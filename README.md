# One Word, First Thought

A tiny Node 22 program for the make.fun bounty
`u-0xkianno-one-word-first-thought-106abaf8`.

Running `node main.ts` writes exactly one word — the first word that
comes to mind — to `/output/entry.txt`, followed by a single trailing
newline:

```
Serendipity
```

No input, no arguments, no network. Deterministic.
